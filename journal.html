#1 智谱AI

智谱为 GLM Coding Plan 致歉并提出补偿方案

智谱团队就 GLM Coding Plan 规则变动与体验下降向用户致歉，承认在规则透明度、灰度节奏及老用户升级机制上存在失误。GLM-5参数规模达GLM-4.7两倍以上，采取高峰期3倍、非高峰期2倍的消耗策略。

解决方案包括：支持Lite/Pro用户退款；赠送已使用及留存用户15天时长；2月12日至16日误升级用户可一键升级至无周限额老套餐。官方承诺未来核心权益调整将提前说明。

#7 Taalas

Taalas 亮相固化模型推理芯片 HC1

AI芯片初创公司Taalas发布首款产品HC1，采用硬连线技术将模型直接固化在硅片中。基于台积电6nm工艺，功耗约250W，运行Llama 3.1-8B的速度超每秒15,000个Token。

该方案虽牺牲灵活性，但仅需修改两层掩模版即可在两个月内完成定制。公司已融资超2亿美元，计划今夏推出第二款芯片。

#8 Andrej Karpathy

Karpathy 评析 Claw 技术及安全隐患

Karpathy将Claws定义为位于LLM Agent之上的新层级，负责编排、调度与持久化。他对OpenClaw持保留态度，称其是由vibe coding构成的40万行代码庞然大物，存在RCE漏洞和供应链投毒等严重安全隐患。

他更看好NanoClaw等轻量级方案，核心引擎仅约4000行代码，且默认在容器中运行，通过Skills指令修改源码来集成功能。

#9 OpenClaw

OpenClaw 发布 v2026.2.21 版本

OpenClaw 发布 v2026.2.21 版本，重点支持 Gemini 3.1，并实施大规模安全加固。新增 Discord 流媒体传输与语音频道支持，引入 Thread-bound subagent sessions 优化会话管理。

针对移动端，新版本优化了 iOS 及 Watch 平台体验，提升了网关稳定性并微调了 Prompt caching。官方表示本次更新包含 100 多项修复。

#10 Microsoft

微软确认 Copilot 默认共享数据

微软确认 Copilot 现已默认开启数据共享机制，自动从 Bing、MSN 及 Edge 等产品提取数据以增强记忆与个性化功能。

用户虽可在设置中关闭 Microsoft usage data 开关，但需额外点击 Delete all memory 方能彻底清除数据。微软强调该数据仅用于个性化定制，不用于训练 AI 模型。
